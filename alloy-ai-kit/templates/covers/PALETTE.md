# MCIT Presentation Palette — "Midnight Noir" (2026-10-14)

Derived from the approved noir hero cover. Replaces the Platinum Silver
system for presentation work. Formal reports keep their own system.

| Token   | Hex       | Use                                    |
|---------|-----------|----------------------------------------|
| Midnight| `#010612` | Primary slide background (near-black navy) |
| Abyss   | `#030F1F` | Panels, cards, secondary surfaces      |
| Royal   | `#1E507A` | Mid blue: data series, secondary elements |
| Pulse   | `#16A6E9` | Electric blue accent: highlights, key data |
| Pale Gold| `#F7EF8A`| Premium accent: ornaments, key highlights, never body text |
| White   | `#FFFFFF` | Primary text                           |
| Silver  | `#B9C2CE` | Secondary text on dark                 |

Rules:
- Dark slides by default; light slides only when content demands it.
- One accent per slide: Pulse for data, Pale Gold for premium moments. Never both competing.
- Pale Gold is for ornaments and single highlights, not charts, not body text.
- The gold divider ornament lives in cover backgrounds only, never inside slides. No generic shape slop.
- Logo always on a constant visible background (white rounded box on dark).
- Typography: Inter, white primary / silver secondary.
