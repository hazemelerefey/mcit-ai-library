# MCIT AI Avatar Collection

Human-style 3D avatars of ancient Egyptian kings, queens, and Thoth, all 512x512 transparent PNG.
Style reference: the Khufu avatar. Each avatar is based on a real historical depiction
(see `../historical-refs/`).

## The Agent

| File | Character |
|------|-----------|
| `../thoth-avatar.png` | **Thoth** — god of wisdom and writing, the main AI agent. Wise human scribe with ibis feather, crescent moon pendant, navy star robe, reed pen. |

## Kings

| File | Character |
|------|-----------|
| `tutankhamun.png` | **Tutankhamun** — the boy king. Golden mask regalia: vulture and cobra brow ornaments, blue and gold nemes, falcon broad collar. |
| `ramesses.png` | **Ramesses II** — Ramesses the Great. Abu Simbel likeness, true pschent double crown, mature commanding presence. |
| `khufu.png` | **Khufu** — builder of the Great Pyramid. Cairo ivory statuette likeness, red crown, golden pyramid emblem. |
| `akhenaten.png` | **Akhenaten** — the heretic king. Karnak colossus likeness, Aten sun disk crown, dreamy gaze. |
