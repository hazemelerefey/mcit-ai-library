# Spreadsheet skill

Use for xls reports, dashboards, and data workbooks. The iron rule:
**real pivot tables and pivot charts built by the tool.** A
Python-computed static table presented as a pivot is a failure.

## When to use

Any request for an Excel report, dashboard, data summary, or .xls/.xlsx
workbook.

## Tools

- **GridCraft** — `~/workspace/tools/gridcraft/` (CLI `gridcraft-cli`)
  — workbooks, real pivot tables, bound pivot charts.
- Supporting playbook: `~/workspace/skills/design-dashboards/`
  (dashboard design judgment: KPIs, layout, visual encoding).

## Workflow

1. **Profile the input.** Row count, columns, grain (one row = ?),
   categorical dimensions, numeric measures. Note the template:
   `../../templates/spreadsheet/TEMPLATE.md`.
2. **Decide the pivots.** One pivot per analytical question
   (e.g. by gender, by country, by age bracket). Each pivot gets
   its own sheet and a bound pivot chart.
3. **Build with GridCraft.** Raw data sheet untouched; pivot sheets
   generated by the tool; front Dashboard sheet with KPI formulas
   referencing the pivots (never typed-in constants).
4. **Verify every KPI.** Recompute each KPI from the raw data
   independently and compare. Totals must reconcile across sheets.
5. **Open every sheet.** Check for: stale sheets from earlier
   attempts, broken internal sheet names, charts bound to the wrong
   range, clipped labels.
6. **Deliver** after full visual review.

## Worked example

Template: `../../templates/spreadsheet/file_example_XLS_5000.xls`
(5,000-row people dataset — see `TEMPLATE.md` for columns).
Built from it: `~/workspace/mcit-ai-library/demo-people-dashboard.xlsx`
with genuine GridCraft pivot tables and bound pivot charts.
Verified values: total 5,000; Female 3,800 (76%), Male 1,200 (24%);
United States 2,400 (48%), Great Britain 1,400 (28%), France 1,200
(24%); age 20s 2,300 / 30s 1,900 / 40s 500 / 50s 300. Dashboard KPI
formulas verified: 5,000 · 76.00% · 48.00%.

## Gotchas

- Delete stale sheets from earlier iterations before delivery —
  leftover sheets with old numbers destroy trust.
- Keep internal sheet naming clean and consistent.
- KPI cells must contain formulas, not values. If the source data
  changes, the dashboard must move with it.
- Chart titles and axis labels must match the pivot they bind to.
